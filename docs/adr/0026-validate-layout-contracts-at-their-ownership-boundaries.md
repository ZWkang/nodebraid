# Validate Layout contracts at their ownership boundaries

Layout validation is split by ownership: the shared projection rejects invalid Requests, Fixed Node IDs, missing Sizes, nesting, and Ports; each Provider validates its typed configuration and algorithm constraints; Runtime validates Proposal revision, exact Node coverage, finite coordinates, and unchanged Fixed Nodes before checking the live revision immediately before commit. NodeBraid copies and freezes its Input, Capability, and validated Proposal shells, accepts explicit zero dimensions, and canonicalizes graph and result order by ID so the same Provider version, input, and effective configuration produce deterministic coordinates. Shared structural failures use only `INVALID_REQUEST`, `INVALID_INPUT`, `UNSUPPORTED_FEATURE`, `INVALID_PROPOSAL`, and `STALE_PROPOSAL`, with bounded diagnostic details rather than copied graph or domain data; Provider-specific failures retain their original values. Cancellation is checked around every asynchronous boundary, while valid empty and all-fixed inputs still exercise the Provider contract instead of taking a silent shortcut; Kernel remains the final authority for Transaction graph invariants.
